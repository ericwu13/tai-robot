【步驟一】解壓縮前先解除封鎖
  1. 對下載的 .zip 檔案按右鍵 → 內容
  2. 在最下方勾選「解除封鎖」→ 確定
  3. 再解壓縮到任意資料夾
  ⚠ 如果沒有先解除封鎖，程式會無法啟動！

【步驟二】首次執行需以系統管理員身分執行
  1. 對 tai_backtest.exe 按右鍵 → 以系統管理員身分執行
  2. 這會自動註冊 COM DLL（只需要一次）
  3. 之後正常雙擊即可執行

【步驟三】Windows SmartScreen 警告
  如果出現「Windows 已保護您的電腦」：
  1. 點選「其他資訊」
  2. 點選「仍要執行」

【步驟四】設定帳號密碼
  1. 編輯 settings.yaml（與 tai_backtest.exe 同資料夾）
  2. 填入你的群益 API 帳號密碼：
     credentials:
       user_id: "你的身分證字號"
       password: "你的密碼"
  3. 或者直接在登入畫面輸入

【步驟五】安裝群益 API 憑證
  1. 到群益證券官網下載並安裝 API 憑證
  2. 沒有憑證會出現 1097 登入錯誤

【步驟六】AI 功能設定（選用）
  在 settings.yaml 中填入 API Key：
  ai:
    provider: "google"              # "anthropic" 或 "google"
    anthropic_api_key: "sk-ant-..."  # Anthropic API Key
    google_api_key: "AIza..."        # Google API Key

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
Headless（無介面）部署
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
不需要安裝 Python，也不需要 git。請在「安裝資料夾」開 cmd 或 PowerShell
（先 cd 到 tai_backtest.exe 所在的資料夾），再貼上指令。

  tai_backtest.exe list
  tai_backtest.exe strategies
  tai_backtest.exe deploy --symbol TMF00 --bot smoke1 --strategy "策略顯示名稱" --mode paper --detach --wait-ready 240
  tai_backtest.exe status --symbol TMF00 --bot smoke1 --json
  tai_backtest.exe stop --symbol TMF00 --bot smoke1 --wait 60
  tai_backtest.exe deploy --symbol TMF00 --bot smoke1 --mode paper --resume --detach --wait-ready 240

說明：
  - 請先用 paper（模擬）。auto 會送出真實委託，只有在你明確要實單時才用。
  - semi_auto 無介面不支援（需要畫面上的下單確認）。請改開 GUI（雙擊 tai_backtest.exe）。
  - 沒有參數、--help，或第一個字不是上面的指令時，會打開 GUI，跟雙擊一樣。
  - 帳號密碼來自同資料夾的 settings.yaml，或環境變數 TAI_USER_ID / TAI_PASSWORD。
    不要把帳號密碼寫進捷徑或工作排程器的參數。
  - 必須在「已登入的桌面工作階段」執行（程式會開一個隱藏的視窗並使用 COM）。
    不支援註冊成 Windows 服務，也不支援以 LocalSystem 執行。
    工作排程器請選「只在使用者登入時執行」，
    「開始於」設成安裝資料夾，並比照 GUI 做解除封鎖與系統管理員註冊。
  - 紀錄在 data\live\{商品}_{機器人名稱}\cli_stdout.log。
    list / status 看到的機器人和 GUI 部署的是同一批資料夾。

常見問題：
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
問題：程式閃退 / 無法啟動
原因：下載的 zip 沒有先解除封鎖就解壓縮
解法：刪除資料夾，回到步驟一重新來過

問題：登入失敗 1097
原因：未安裝群益 API 憑證
解法：到群益證券官網下載安裝憑證

問題：COM 註冊失敗
原因：沒有以系統管理員身分執行
解法：對 EXE 按右鍵 → 以系統管理員身分執行

問題：圖表空白
原因：未安裝 WebView2 Runtime
解法：下載安裝 https://go.microsoft.com/fwlink/p/?LinkId=2124703

問題：開圖表時出現 Python.Runtime.dll 錯誤
原因：下載的 zip 沒有先解除封鎖就解壓縮（最常見），或 .NET Framework 4.8 未啟用
解法：
  1. 程式會自動嘗試解除封鎖，重新開圖表試試
  2. 如果還是不行：刪除資料夾，回到步驟一重新解壓（記得先解除封鎖 zip）
  3. 確認 .NET Framework 4.8 已啟用：
     「設定」→「應用程式」→「選用功能」→「更多 Windows 功能」
     → 勾選「.NET Framework 4.8 Advanced Services」
